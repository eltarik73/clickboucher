## 2. Ce qui n'a pas été repris

- V3 : « un humain relit et approuve avant fusion » est remplacé par le contrôle Fable du
  programme (`klikgo-programme` § 2) ; le propriétaire veut des agents autonomes.
- V8 : « pour une petite modification, faire confiance aux types et laisser la CI trouver » n'est
  pas repris : `klikgo-programme` § 7 exige les portes avant toute annonce.
- V1 : ton absolu (« sauter une étape = mentir ») remplacé par le pourquoi de chaque règle, comme le
  demandent les bonnes pratiques actuelles de Claude Code (V4).
