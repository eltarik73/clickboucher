| PG5 | https://www.postgresql.org/docs/current/indexes-multicolumn.html | Index composé : égalités sur les colonnes de tête, puis une inégalité sur la première colonne sans égalité, bornent la portion lue ; « should be used sparingly », rarement utile au-delà de trois colonnes |
