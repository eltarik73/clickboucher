# Sources — conformite-france

Consultées les 2026-11-13 et 2026-11-14, puis **revérifiées une à une le 2026-11-14** (relecture
indépendante). Toutes sont des sources publiques **officielles** (autorités françaises ou européennes,
Légifrance, Office des publications de l'UE, juridictions) ou la documentation **first-party** des
outils utilisés. Aucune source communautaire (Reddit, blog, cabinet d'avocats) ne fonde une règle.
Résumés rédigés par nous ; citations courtes.

Statut : **Lu** = page officielle ouverte et lue pendant la vérification ; **Extrait** = contenu connu
par un résultat de recherche seulement (page inaccessible à l'outil, HTTP 403) : à relire à la main
avant de s'en servir dans un texte juridique.

Accès : `economie.gouv.fr` refuse l'accès automatisé (403) ; `eur-lex.europa.eu` renvoie une page de
contrôle. Les textes de l'UE ont été lus sur l'Office des publications :
`curl -L -H "Accept: application/xhtml+xml" -H "Accept-Language: eng" https://publications.europa.eu/resource/celex/<CELEX>`.
