# Sources de klikgo-review

Tout le texte du skill est rédigé par nous, en français. Les sources sous licence permissive (MIT,
Apache-2.0, CC-BY) sont **adaptées** : idée reprise, reformulée et modifiée pour Klik&Go, avec
attribution ci-dessous. Les sources CC-BY-SA, AGPL ou sans licence ne fournissent que des
**idées**, reformulées, sans texte ni code. Étoiles et date du dernier push lus sur l'API GitHub
le 2026-11-14 par les éclaireurs du programme ; fichiers lus le 2026-11-14.

## 4. Écarté, et pourquoi

- Agents génériques de VoltAgent (`code-reviewer`, `refactoring-specialist`) : listes sans raison,
  seuils inventés (couverture, complexité), relecteurs munis d'outils d'écriture.
- wshobson/agents (`code-review-excellence`) : conseils pour équipes humaines, sans ancrage.
- Le score de confiance sur 100 de l'ancien skill : remplacé par la validation contradictoire
  (§ 8), qui produit une preuve au lieu d'un chiffre.
- Les échelles Critical/High/Medium/Low et WILL BREAK/COST/ROT : une seule échelle dans le
  programme.
- Les règles amont contraires au dépôt (liste dans les Pièges du `SKILL.md`).
