# Skills Klik&Go — index

Relevé du 2026-11-14. Une ligne par dossier de `.claude/skills/` : quand le lire, et son statut.
Pour choisir les skills d'une tâche, partir de la table § 11 de
[`klikgo-programme`](klikgo-programme/SKILL.md). Les fiches de rôle des équipes sont dans
[`../agents/`](../agents/) (`klikgo-chef-de-chantier`, `klikgo-ingenieur-backend`,
`klikgo-ingenieur-front`, `klikgo-ingenieur-plateforme`, `klikgo-designer`, `klikgo-referenceur`,
`klikgo-testeur-recette`, `klikgo-relecteur`, `klikgo-auditeur-securite`).

**Précédence** : `CLAUDE.md` > `seo-anti-penalty` (indexation) > skills du programme > skills
préexistants. Un skill préexistant qui contredit `CLAUDE.md` ou un skill du programme ne fait pas
foi (exemples ci-dessous).

## Statuts

- **Vérifié 2026-11** : écrit ou réécrit par le programme, ancré dans le code, puis relu, et
  corrigé au besoin, par un vérificateur indépendant les 13 et 14 novembre 2026. Les limites
  restantes sont écrites dans chaque skill, souvent en « Points à arbitrer ». Ses chiffres sont
  une photographie : les relancer avant de les citer.
- **Préexistant, non revérifié** : antérieur au programme (souvent février–mai 2026, connaissances
  génériques) ; non relu ; à prendre avec prudence.
