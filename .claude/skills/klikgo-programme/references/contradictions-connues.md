le contrôle de ce manuel : chaque ligne a été retrouvée dans les fichiers des skills cités. Les
mesures de production qu'elles rapportent (`seo-expert`, `web-performance`,

signale dans `pointsAArbitrer` ou demande au directeur la mise à jour du skill concerné. Toujours
revérifier dans le code : l'arbre bouge (chantier 0 non commité au relevé).
