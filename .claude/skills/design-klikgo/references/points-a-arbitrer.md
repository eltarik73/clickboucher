# Points à arbitrer

Ces points demandent une décision du fondateur : soit la recherche contredit ou précise une règle de `CLAUDE.md`, soit le changement est visible sur tout le site. Tant qu'un point n'est pas tranché, la règle de `CLAUDE.md` et la colonne « en attendant » s'appliquent. Aucun agent ne tranche seul.

| A19 | **Mouvement réduit : filet ciblé ou règle globale** | Aucune règle `prefers-reduced-motion` dans `globals.css`. Même point dans le skill `accessibility-wcag` (son n° 9). | Filet ciblé, complété par `motion-safe:` dans le code nouveau.
